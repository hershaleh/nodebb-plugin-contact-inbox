# NodeBB Contact Inbox

תוסף NodeBB 4.x לניהול פרטי של פניות מטופס צור קשר.

## יכולות

- API ציבורי לקבלת פניות אנונימיות: שם, דוא״ל, נושא והודעה.
- תיבת פניות פרטית בכתובת `/plugins/contact-inbox`.
- סמל מעטפה בסרגל הניווט עם מספר הפניות שטרם נפתחו, המוצג רק למורשים.
- ברירת מחדל: קבוצת `administrators`; מנהל יכול להוסיף קבוצות נוספות לפי שם הקבוצה.
- פתיחת פנייה מסמנת אותה כנקראה לכל הצוות.
- חיפוש, סינון לפי סטטוס, עדכון סטטוס ומחיקה.
- קישור לצ'אט עם משתמש רשום כאשר נמצא משתמש תואם.
- היסטוריית תשובות פנימית.
- התראות דוא״ל לפי בחירת כל איש צוות, לכתובת אישית שהגדיר.
- תשובת דוא״ל אופציונלית, רק לאחר הפעלתה בהגדרות התוסף והפעלת SMTP בהגדרות הדוא״ל של NodeBB.
- שמירת נתונים במסד הנתונים של NodeBB.
- הגבלת קצב שליחה לפי כתובת IP.
- מחיקה אוטומטית לפי תקופת שמירה; ברירת המחדל היא 0 (מחיקה ידנית בלבד).

## התקנה

התקנה דרך npm (לאחר פרסום החבילה) או דרך GitHub אם מנהל התוספים בשרת תומך בהתקנה מכתובת Git:

`https://github.com/hershaleh/nodebb-plugin-contact-inbox`

לאחר התקנה/עדכון יש לבצע NodeBB build ולהפעיל מחדש את NodeBB.

## חיבור טופס Custom Pages

שליחת הטופס מתבצעת לנתיב NodeBB v4:

`POST /api/v3/plugins/contact-inbox/submissions`

JSON לדוגמה:

```js
const token = document.querySelector('meta[name="csrf-token"]')?.content;
const response = await fetch('/api/v3/plugins/contact-inbox/submissions', {
  method: 'POST',
  credentials: 'same-origin',
  headers: {
    'Content-Type': 'application/json',
    ...(token ? { 'x-csrf-token': token } : {}),
  },
  body: JSON.stringify({ name, email, subject, message }),
});
const result = await response.json();
if (!response.ok) throw new Error(result.error || 'שליחת הפנייה נכשלה');
```

השדות הנדרשים: `name`, `email`, `subject`, `message`. אם הפונה מחובר לפורום, התוסף משייך את הפנייה אוטומטית לחשבון המאומת שלו. שדה username שנשלח מטופס ציבורי אינו מהימן ולא יוצר קישור לצ'אט, כדי למנוע התחזות.

## הגדרות

- **קבוצות מורשות:** שמות קבוצות מופרדים בפסיקים. קבוצת administrators תמיד נשארת מורשית.
- **מחיקה אוטומטית:** 0 מבטל מחיקה אוטומטית; אחרת מספר הימים לשמירת פנייה. ניקוי מתבצע בעת הפעלת התוסף ולאחר מכן מדי שעה.
- **הגבלת שליחה:** מספר פניות לשעה מכתובת IP.
- **התראות דוא״ל:** המנהל מפעיל את היכולת; כל איש צוות נרשם בנפרד ומגדיר כתובת משלו.
- **תשובות בדוא״ל:** נדרש SMTP פעיל ב-NodeBB; ללא SMTP האפשרות לא תישמר כפעילה.
